# Literally Illiterate — Native iOS

Native iOS wrapper for Literally Illiterate.

This project will provide:

- WKWebView integration with the Literally Illiterate web app
- StoreKit 2 native in-app purchases
- JavaScript ↔ native StoreKit bridge
- Apple transaction handling
- GitHub Actions build pipeline for iOS

The Base44 application source remains separate from this native iOS project.
