Literally Illiterate iOS app icons
Each PNG is square, RGB (opaque), and named to match the filenames visible in the GitHub AppIcon.appiconset screenshot.
Upload these files into ios/Assets.xcassets/AppIcon.appiconset/ and replace the corresponding old files.
Do not replace Contents.json unless its filenames need updating.
Confirm the icon mappings in Contents.json and create a new native iOS build for App Store submission.
